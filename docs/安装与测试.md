# 安装与测试

## 免管理员版

1. 保存文件并完全退出 PowerPoint。
2. 运行 `installers/ImageLink-User-Setup-0.2.0.exe`。
3. 选择“安装 / 修复”。不要使用“以管理员身份运行”。
4. 重新打开 PowerPoint，确认功能区出现“图片关联”。

免管理员版安装到当前用户的 LocalAppData 目录，并写入当前用户的 Office COM 加载项注册信息。公司策略仍可能禁止加载未经批准的 COM 加载项。

## 管理员版

1. 保存文件并完全退出 PowerPoint。
2. 运行 `installers/ImageLink-Setup-0.2.0.exe`。
3. 确认管理员权限并选择“安装 / 修复”。
4. 重新打开 PowerPoint，确认功能区出现“图片关联”。

## 建议测试项目

- 同一图片在两个页面中使用不同尺寸和裁剪，更新后分别保持原构图。
- 把其中一个实例裁剪为圆形，更新后仍保持圆形。
- 给图片添加普通进入动画，更新后动画类型、顺序和时长仍符合预期。
- 使用一张没有动画的图片更新，确认不再出现 `Shape.PickupAnimation: Invalid Request`。
- 保存、关闭并重新打开 PPT，确认关联仍然存在。

建议先使用演示文稿副本测试。安装管理员版或免管理员版中的一个即可，不要同时启用。
