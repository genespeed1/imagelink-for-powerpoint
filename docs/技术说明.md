# 技术说明

ImageLink 是一个使用 C# 编写的 PowerPoint COM 加载项，面向 Windows 桌面版 PowerPoint。

## 关联方式

插件使用 PowerPoint Shape Tags 在每个图片对象上保存关联组标识和名称。标签随普通复制粘贴进入其他幻灯片，并随 PPTX 文件保存，因此不依赖外部路径或数据库。

## 更新流程

1. 扫描当前演示文稿，找出关联组内的全部图片。
2. 保存临时校验快照，检查占位符、组合、自定义几何、复杂效果和跨对象关系。
3. 为每个位置暂存新图片。
4. 恢复原图片框、裁剪尺寸和偏移、内置裁剪形状、旋转、翻转、层级、标签及普通动画。
5. 所有暂存对象准备成功后，再统一删除原图片并提交替换。
6. 失败时删除暂存对象并保留原图片。

临时校验快照在检查后立即删除，它不是用户备份。正式文稿仍由 PowerPoint 自身保存和恢复。

## 主要接口和格式

- Office COM 加载项接口和 Ribbon XML。
- PowerPoint Shape、Tags、PictureFormat.Crop、AutoShapeType 和 TimeLine 动画接口。
- Open XML/PPTX 包结构，用于替换前的安全检查。
- Windows 当前用户或本机范围的 COM 注册。

## 测试

源码包含离线逻辑测试、功能区与右键菜单测试、选择状态检查、注册验证和 PowerPoint 集成冒烟测试。0.2.0 的离线测试覆盖普通裁剪、内置形状裁剪、无动画更新、动画迁移、事务回滚和关联标签保留。
